# Base de Datos - Tienda de Barrio

## Descripción

Este repositorio contiene el levantamiento de requisitos para el
desarrollo de una base de datos destinada a la gestión de una
tienda de barrio.

El negocio comercializa diferentes tipos de productos, como
bebidas, dulces, productos salados, helados, alimentos,
condimentos y productos de higiene.

## Objetivo

Identificar las principales necesidades y problemas del negocio
para posteriormente diseñar una base de datos que permita
gestionar productos, inventario, ventas, compras y proveedores.

## Contenido

- Entrevista y necesidades del negocio.
- Identificación de problemas.
- Requisitos iniciales del sistema.
- Análisis de posibles entidades y relaciones.
